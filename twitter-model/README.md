# Twitter SQL Model

A simplistic mini Twitter model using SQL (DuckDB), built interactively in a Marimo notebook.

## Getting Started

Because this is part of the `mini-data-apps` workspace, make sure to install dependencies from the root directory:

```bash
cd ..
uv sync
```

To run the notebook interactively:

```bash
uv run marimo edit twitter-model/tweet_sql.py
```
